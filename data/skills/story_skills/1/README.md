项目简介

故事发生在大卫死亡之后数年，露西的意识在“月球计划”中发生异常融合，形成不可控的复合人格数据体 ECHO-17，并开始在夜之城与轨道网络之间以“幽灵信号”形式扩散。

夜之城由此进入新的阶段：

人类意识不再只属于肉体，而成为可污染、可复制、可残留的数据结构。
